SECTION 02 ─ 放水 14 / 23

65mmホースで考える摩擦損失

「摩擦損失」ってなに？

ポンプから水を送り出しても、ホースの中を水が流れるうちに、水とホース内側の壁がこすれて水の勢い（圧力）がどんどん落ちていきます。これが「摩擦損失」です。
ホースが長くなればなるほど、筒先に届く圧力が下がるのはこのせいです。

流量を2倍にすると、損失は4倍

65mmホースで毎分500L流しているときの損失を「1」とします。毎分1,000L（2倍）に増やすとホースの太さは同じなので水の速さが2倍に。すると――

  • 内壁にぶつかる水の量が2倍
  • ぶつかる1つ1つの水の勢いも2倍

このかけ算で 2 × 2 ＝ 4倍 の摩擦損失になります。

流量と摩擦損失の関係

流量水の速さ摩擦損失
500 L/min（基準）1倍1倍
1,000 L/min（2倍）2倍4倍
1,500 L/min（3倍）3倍9倍

現場で何が起きるか？

摩擦損失が4倍になるということは、ポンプの送水圧力をかなり上げないと筒先で必要な放水圧力が確保できなくなるということです。ホースの接続方法や延長距離によっても損失は大きく変わります。

💡
ひとことまとめ：同じ65mmホースに水を2倍流すと、摩擦で失われる圧力は4倍。だから現場ではホースの延長方法や分岐の使い方をしっかり考えて運用することが重要です。
SECTION 02 ─ 放水 15 / 23

摩擦損失の計算

摩擦損失とは

  • 水がホース内壁と接触して生じる抵抗による圧力低下
  • ホースが長いほど、流量が多いほど損失は大きくなる

摩擦損失に影響する3要素

ホース径

径が小さいほど損失大

延長距離

本数に比例して増加

放水量

流量の2乗に比例して増加

計算式

Pf = c × n

記号意味
Pf摩擦損失圧力（MPa）
cホース1本あたりの摩擦損失係数（MPa/本）
nホース本数（1本 = 20m）
💡
なぜ流量の2乗に比例するか？
流速が上がると水とホース内壁の摩擦が急増するため。流量が2倍 → 損失は約4倍になる。係数 c にはこの流量条件が含まれる。
⚠
分岐金具の損失：分岐金具を使用する場合、金具自体の抵抗により0.1 MPa の摩擦損失が別途発生する。計算時に加算すること。
SECTION 02 ─ 放水 16 / 23

送水圧力の計算方法

Ps = Pn + Pf + Pb + Ph

送水圧力 ＝ ノズル先端圧力 ＋ 摩擦損失 ＋ 分岐金具損失 ＋ 落差圧

各要素の意味

記号内容目安
Ps送水圧力計算で求める
Pnノズル先端圧力0.3 MPa
Pf摩擦損失（ホース）0.03 × n で算出
Pb分岐金具損失使用時 0.1 MPa
Ph落差圧（高低差）高さ1m ＝ 0.01 MPa

計算例 1（分岐金具なし）

条件：65mmホース 5本・c=0.03・高低差10m上り

Ps = 0.3 + (0.03×5) + 0 + (0.01×10) = 0.55 MPa

計算例 2（分岐金具あり）

同条件 ＋ 分岐金具使用

Ps = 0.3 + (0.03×5) + 0.1 + (0.01×10) = 0.65 MPa

📋
現場での計算は困難なため、ホース本数・高低差・分岐金具の有無ごとに事前に計算した送水圧力表を作成し、ポンプ付近に携行・掲示しておくことが極めて有効です。
